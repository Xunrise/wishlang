# Decisions

Architectural and dependency decisions made while implementing this project.
Generated by wishlang from `.wish/decisions.json`; change status with `wish decide <id> accept|reject`.

## 001 Windowing backend (proposed)

- **Kind:** dependency
- **Choice:** winit 0.30 with its ApplicationHandler event loop API
- **Crates:** winit
- **Alternatives:** tao; sdl2; eframe/egui; a stub that only records the mode
- **Why:** `open(Mode::Maximized).run()` implies a real window. winit is the standard, minimal cross-platform window crate and supports requesting a maximized window.

## 002 Error strategy for run() (proposed)

- **Kind:** architecture
- **Choice:** `run()` returns `()` and panics with a message if the event loop or window can't be created
- **Alternatives:** return Result and require `?` or unwrap in main
- **Why:** main's last expression is `.run()` with no semicolon, so it has to evaluate to `()`.
